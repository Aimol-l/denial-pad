D行为与边界实现约束

解析顺序

选中主题 → hicolor → Adwaita → 其余已安装主题。应用自带的 pixmaps/hicolor 图标仍然优先，符合 freedesktop 规则。

安装位置

用户主题装到 ~/.local/share/icons/<id>；扫描 $XDG_DATA_DIRS/icons，系统主题只读。

安全

拒绝绝对路径与 ..；不跟随符号链接；只接受普通文件；解包后校验 index.theme 与 [Icon Theme] 段。

刷新

安装/删除后刷新目录缓存并重建主题网格；换主题时启动器、任务栏、通知图标一起重解析，无需重启。

空状态

只有系统主题时也显示网格；「跟随明暗」始终存在。安装按钮在导入期间禁用并显示进度。
