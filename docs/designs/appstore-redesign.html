规则：商店内不出现任何硬编码主题色。所有 accent 元素（按钮、rail 选中 pill、banner 按钮、 更新徽标、搜索聚焦边框）全部取自 Denial settings 的全局色调变量；用户在 settings 选色或开"从壁纸取色"后 立即生效。来源徽标三色（extra 蓝/aur 琥珀/android 绿）是数据语义色，不随主题变—— 它们标识"软件来自哪里"，必须可区分。

边界与状态

场景UI 行为
单个后端查询失败该源区域显示"暂不可用"占位，其他源正常（adb 断了只影响 Android 区）
后端 CLI 不存在该源整体隐藏（如未装 android-tools 时推荐页无 APK 卡）
pacman 依赖冲突确认框展示冲突详情 + "查看完整输出"，不自动解决
APK 安装失败解析原因：签名冲突 / ABI 不兼容（x86 包）/ 空间不足
卸载移除多个桌面入口详情页"卸载影响"列出全部入口，确认框再列一次
提权被取消反馈"未安装：认证被取消"，不静默重试
竖屏使用rail 保持（玲珑截图即左栏结构，竖屏同样成立）
settings 卸载入口settings 内仅本地快捷卸载（不搜仓库），完整管理来本插件
